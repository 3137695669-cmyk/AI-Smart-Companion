================================================================================
                        AI 智能伴侣 项目介绍与使用说明
================================================================================


一、项目简介
--------------------------------------------------------------------------------

AI智能伴侣 是一个基于 Streamlit 的网页聊天应用，底层调用 DeepSeek 大模型
（deepseek-v4-pro），以「情侣/陪伴」的口吻与用户聊天。

它解决的核心问题：
  1. 每个用户使用「自己的」 DeepSeek API Key，而非开发者统一提供一个 key；
  2. 提供账号注册/登录体系，聊天历史记录按用户隔离保存；
  3. 历史对话、昵称、性格、API Key 全部存入 MySQL，换设备/换浏览器都不丢。


二、主要功能
--------------------------------------------------------------------------------

  1. 账号注册 / 登录 / 退出登录（手机号即登录账号）
  2. 每个用户独立填写并保存自己的 DeepSeek API Key（加密存储）
  3. AI 流式聊天（支持 emoji、微信式简短回复）
  4. 可自定义「昵称」和「性格」人设
  5. 会话管理：新建会话、查看历史会话、删除会话
  6. 历史记录持久化到 MySQL，按用户隔离
  7. 显示名：可选、可重复，仅作展示用


三、技术栈
--------------------------------------------------------------------------------

  - 语言         : Python 3.13
  - Web 框架     : Streamlit
  - 大模型调用   : openai SDK（对接 DeepSeek 兼容接口）
  - 数据库       : MySQL 8.0（驱动 pymysql）
  - 密码哈希     : bcrypt
  - API Key 加密 : cryptography（Fernet 对称加密）


四、文件结构
--------------------------------------------------------------------------------

  AI Smart Companion.py     主应用（登录/注册页 + 聊天界面 + 侧边栏）
  config.py                 配置：MySQL 连接信息 + 加密密钥（敏感，勿提交 git）
  db.py                     数据库层：连接、自动建库建表、CRUD
  auth.py                   认证层：密码哈希、API Key 加解密、注册/登录
  requirements.txt          Python 依赖清单
  伴侣logo.png              页面 logo
  launcher.py               启动器源码（重新打包 exe 时用）
  启动AI伴侣.exe            双击即可启动应用的桌面启动器
  .gitignore                忽略 .venv / config.py / 构建产物等


五、环境准备（首次使用，按顺序做）
--------------------------------------------------------------------------------

第 1 步：安装 MySQL 8.0
  - 本项目依赖本机已安装的 MySQL 8.0（Windows 服务名 MySQL80，端口 3306）。
  - 确认服务已启动：在「服务」里找到 MySQL80，确保状态为「正在运行」。

第 2 步：安装 Python 依赖
  项目使用虚拟环境 .venv，依赖已经装好。如果换机器或重新建环境，执行：

      python -m venv .venv
      .venv\Scripts\activate
      pip install -r requirements.txt

第 3 步：填写 config.py（唯一需要手动改的地方）
  打开 config.py，把 DB_PASSWORD 改成你自己的 MySQL root 密码：

      DB_PASSWORD = "你的 root 密码"

  其余字段说明：
      DB_HOST    数据库地址，本机默认 127.0.0.1
      DB_PORT    端口，默认 3306
      DB_USER    账号，默认 root
      DB_NAME    库名，程序会自动创建，默认 ai_companion
      SECRET_KEY 用于加密 API Key，已随机生成，【不要更改】；
                 一旦改了，之前用户加密存的 API Key 将无法解密。


六、启动运行
--------------------------------------------------------------------------------

方式一（推荐，最简单）：
  双击项目根目录下的「启动AI伴侣.exe」。
  它会自动用项目自带的虚拟环境启动应用，等服务就绪后自动打开浏览器。
  关闭那个命令行窗口即可停止应用。

方式二（命令行）：
  在项目根目录打开终端，执行：

      .venv\Scripts\streamlit.exe run "AI Smart Companion.py"

启动后会自动：
  1. 连接 MySQL；
  2. 首次运行自动创建数据库 ai_companion 和三张表（users / sessions / messages）。

看到如下提示表示启动成功：

      Local URL: http://localhost:8501

然后用浏览器打开 http://localhost:8501 即可。

补充：如果 8501 端口被占用，启动器会提示端口不可用；请先关闭占用该端口的
程序，或在命令行用 --server.port 指定其他端口（见 FAQ Q5）。


七、使用方法（用户视角）
--------------------------------------------------------------------------------

  1. 注册账号
     首次打开会进入「登录 / 注册」页，切到「注册」标签：
       - 填手机号（登录账号，必填、唯一）和密码；
       - 显示名可选（可重复，仅作展示用，之后也能改）；
       - DeepSeek API Key 可选（之后也能补填）；
       - 点「注册」即自动登录进入主界面。

  2. 登录账号
     之后每次打开，用「手机号 + 密码」登录即可。
     左侧边栏「显示名设置」可随时修改显示名（允许与他人重复）。

  3. 填写 API Key
     登录后，在左侧边栏点开「API Key 设置」，
     粘贴你的 DeepSeek API Key，点「保存 API Key」。
     没填 key 之前聊天会提示，先填了才能用。

  4. 聊天
     在页面底部输入框输入内容回车，即可与 AI 伴侣对话（流式输出）。

  5. 设置人设
     侧边栏「伴侣信息」里可修改「昵称」和「性格」，影响 AI 的回复口吻。

  6. 会话管理
     - 「新建会话」：结束当前会话，开一个全新的对话；
     - 「历史会话」：点击任意历史会话名可切换回去继续聊；
     - 垃圾桶图标：删除对应会话（消息会一并删除）。

  7. 退出登录
     侧边栏顶部「退出登录」按钮。重新登录后历史记录仍在。


八、数据库结构
--------------------------------------------------------------------------------

  数据库：ai_companion（utf8mb4，支持中文和 emoji）

  表 users（用户）
      id                 自增主键
      phone              手机号（登录账号，必填、唯一）
      password_hash      bcrypt 密码哈希
      username           显示名（可选、可重复，仅展示用）
      api_key_encrypted  加密后的 DeepSeek API Key（可为空）
      created_at         注册时间

  表 sessions（会话）
      id           自增主键
      user_id      所属用户（外键，级联删除）
      session_name 会话名（时间戳生成，同用户内唯一）
      personality  性格人设
      nick_name    昵称
      created_at   创建时间

  表 messages（消息）
      id         自增主键
      session_id 所属会话（外键，级联删除）
      role       角色：user / assistant
      content    消息内容
      created_at 发送时间


九、常见问题（FAQ）
--------------------------------------------------------------------------------

  Q1：启动报「数据库连接失败」
     → 检查 config.py 的 DB_PASSWORD 是否填对；
     → 确认 MySQL80 服务是否正在运行。

  Q2：聊天提示让我先填 API Key
     → 到左侧「API Key 设置」里粘贴你自己的 DeepSeek API Key 并保存。

  Q3：填了 key 但调用报错
     → 确认 key 是否有效、是否有余额；
     → 确认能正常访问 https://api.deepseek.com（需联网）。

  Q4：换了个账号登录，能看到别人的历史吗？
     → 不会。所有会话和消息都按 user_id 隔离。

  Q5：想改端口或允许局域网访问
     → 启动时加参数，例如：
       .venv\Scripts\streamlit.exe run "AI Smart Companion.py" --server.port 8080

  Q6：SECRET_KEY 能改吗？
     → 可以，但改完之前所有用户加密存的 API Key 都无法再解密，需要重新填写。
       所以建议一开始就确定好，之后不再改。

  Q7：显示名能重复吗？
     → 能。显示名只是展示用，允许与他人重复，随时可在侧边栏「显示名设置」里改。

  Q8：手机号是必填吗？会发验证码吗？
     → 必填且唯一，是登录账号（登录时用「手机号 + 密码」）。目前只做格式校验
       （6~20 位数字），不发送短信验证码；重复注册会提示「该手机号已被注册」。
       注意：因为暂未接短信验证码，任何人都能随便填一个手机号注册（占号风险），
       手机号本身不保证归属真实性。


十、安全提示
--------------------------------------------------------------------------------

  - config.py 含数据库密码和加密密钥，已加入 .gitignore，请勿提交到代码仓库；
  - root 密码建议不要使用弱密码（如 123456），尤其机器联网时；
  - API Key 在数据库中为密文存储，但登录态仅保存在浏览器会话内，
    退出登录即失效。
